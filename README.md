# architecture-insuretech

Проектная работа 8 спринта курса «Архитектура программного обеспечения: продвинутый уровень» от Яндекс.Практикума.

Кейс: компания InsureTech - агрегатор страховых услуг для частных и корпоративных клиентов. Задача - спроектировать масштабируемую и отказоустойчивую архитектуру на фоне растущей нагрузки.

## Структура

- [project_overview.md](project_overview.md) - описание кейса и архитектуры компании
- [how_to_complete_project.md](how_to_complete_project.md) - требования к сдаче работы
- [Task1](Task1) - Проектирование технологической архитектуры
- [Task2](Task2) - Динамическое масштабирование контейнеров
- [Task3](Task3) - Переход на Event-Driven архитектуру
- [Task4](Task4) - Проектирование продажи ОСАГО
- [Task5](Task5) - Проектирование GraphQL API
- [Task6](Task6) - Настройка Rate Limiting
- [templates](templates) - общие шаблоны для подготовки (библиотеки иконок Yandex Cloud для draw.io)
- [images](images) - общие картинки кейса (C4-диаграмма и др.)

## Как сдавать

Работа сдаётся через пул-реквест. Подробнее - в [how_to_complete_project.md](how_to_complete_project.md).
